1. 协议的接受

本协议是你与WenDou Ai（WenDou Ai，以下简称“我们”）之间关于使用 WenDou Agent、Eonarc 及相关账号服务和官网（统称“服务”）的约定。注册、登录、下载或使用服务，即表示你已阅读并同意本协议和《隐私政策》。

2. 账号

  • 你应使用本人可以接收邮件的邮箱注册，并妥善保管密码、恢复码和登录设备；
  • 账号仅限你本人使用，不得出借、转让或出售；
  • 发现账号被盗用，请立即修改密码、退出所有设备并联系我们；
  • 违反本协议时，我们可以停用账号并撤销其登录会话。

3. 测试阶段与服务变化

服务目前处于测试阶段。功能、可用模型、使用额度和服务时间可能调整，也可能因维护或故障中断。积分与计费功能尚未启用；如果将来开始收费，我们会提前公告收费规则，不会追溯收取此前的费用。

4. WenDou Agent 本机执行

WenDou Agent 在你的电脑上、在你授权的范围内读写文件、运行命令、操作浏览器，并在获得系统授权后操作电脑界面。你应：

  • 只把需要处理的目录设为工作区，谨慎授予系统权限；
  • 批准操作前确认内容，对批准后产生的结果负责；
  • 定期备份重要数据。AI 可能误解指令或执行出错。

5. Eonarc 云端执行

Eonarc 在资源受限的隔离云端环境中执行任务。服务重启时，正在执行的任务会被标记为中断，不会自动重新执行，以免重复产生外部影响。你可以查看已有结果后重新发起。

6. AI 生成内容

AI 生成的内容可能不准确、不完整或已过时，不构成法律、医疗、金融等专业意见。你应自行核实，并对使用这些内容的决定负责。

7. 使用规范

你不得利用服务：

  • 从事违法活动，或制作、传播违法和侵权内容；
  • 开发或传播恶意软件，攻击、扫描或入侵未经授权的系统；
  • 批量注册账号、转售或共享模型额度，或以其他方式绕过服务限制；
  • 干扰服务正常运行，或未经许可对 WenDou Agent、Eonarc 的非开源部分进行反向工程。

8. 知识产权

WenDou Agent、Eonarc、WenDou Ai 与WenDou Ai的名称、标志和软件归我们所有。WenDouOs 按 MIT 许可开源，你可依该许可使用。

你提交的内容和服务为你生成的结果归你所有。为提供服务，你授权我们在必要范围内存储、处理和传输这些内容。

9. 软件下载与更新

WenDou Agent Windows 安装程序 WenDou.exe 可从官网“下载”页面获取。请确认文件名后再运行；未经我们许可，不得再分发 WenDou Agent 安装包。

10. 第三方服务

服务会用到模型服务提供方、GitHub 等第三方服务。第三方服务的可用性和内容由其提供方负责，你使用时还应遵守其条款。

11. 免责与责任限制

服务按现状提供。在法律允许的最大范围内，我们不保证服务不中断、无错误或满足你的特定需求，也不对间接损失、利润损失或数据丢失承担责任。我们对你承担的全部责任，以你在争议发生前 12 个月内为服务实际支付的费用为限。

12. 终止

你可以随时停止使用服务并申请注销账号。你违反本协议时，我们可以暂停或终止向你提供服务。协议终止后，知识产权、免责与责任限制、法律适用等条款继续有效。

13. 法律适用与争议解决

本协议适用中华人民共和国法律。双方应友好协商解决争议；协商不成的，任一方可向我们所在地有管辖权的人民法院提起诉讼。

14. 变更与联系

我们可能会更新本协议，重大变更会提前在官网或应用内提示。更新后继续使用服务，即表示你接受更新后的协议。对本协议有任何疑问，请联系 zhangkongduan@gmail.com。
