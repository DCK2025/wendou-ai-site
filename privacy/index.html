1. 适用范围

本政策说明WenDou Ai（WenDou Ai，以下简称“我们”）在你使用以下服务时如何处理个人信息：

  • 官网 www.mvc1225.cn；
  • WenDou Agent 桌面应用及其账号服务（含托管模型服务）；
  • Eonarc 移动应用及其云端服务。

WenDouOs 是 MIT 许可的开源软件。你自行下载、部署和运行 WenDouOs 时，数据由你或你的部署方处理，不经过我们，本政策不适用于此类使用。

2. 我们收集的信息

账号信息

注册和登录时，我们收集你的邮箱、显示名称和你选择上传的头像。密码只以加盐哈希形式保存，我们无法得知密码原文。使用 GitHub 登录时，我们会获取你的 GitHub 账号标识和已验证邮箱，不会保存 GitHub 访问令牌。Eonarc 账号的恢复码只保存哈希，邀请注册会记录所用邀请码。

登录会话

我们保存登录设备会话及其创建、刷新、到期时间，以便你保持登录、查看设备和退出其他设备。会话令牌在服务器上只保存摘要。

WenDou Agent 本机数据

项目、会话记录、附件、本地设置，以及你填写的自定义 API 地址和密钥，保存在你的电脑上。登录账号不会上传这些内容。使用自定义 API 时，请求由你的电脑直接发送给你配置的服务方，不经过我们。启用远程控制时，任务执行和模型凭据仍保留在你的电脑上。

WenDou Agent 托管模型

使用我们提供的托管模型时，你在任务中交给模型的内容（包括文字、文件片段和工具执行结果）会经我们的服务器转发给模型服务提供方。我们为每次调用记录账号、模型、状态、耗时、用量和错误摘要，用于额度管理、排查故障和防止滥用，这些记录保留 90 天，不包含请求与回复正文。

Eonarc 云端内容

Eonarc 在云端执行任务，因此我们会存储你的对话、消息、上传的图片与文件、任务及其进度事件，以及代理在你的个人空间中保存的记忆和工作文件。这些数据按账号隔离存储；每次任务在隔离容器中运行，只挂载你本人的空间。生成回复时，相关内容会发送给后台配置的模型服务提供方。

访问日志

为保障安全和排查故障，我们的服务器会记录访问日志，包括 IP 地址、访问时间、请求路径、来源页面和浏览器标识。官网不使用 Cookie，不加载第三方统计、广告或追踪脚本。

3. 我们如何使用信息

  • 提供、维护服务，完成你发起的任务；
  • 验证身份，保障账号与服务安全，识别和处理滥用；
  • 发送验证码等与服务直接相关的通知；
  • 排查故障，改进产品的稳定性和体验。

我们不会出售你的个人信息，不会将其用于广告投放，也不会用你的内容训练模型。

4. 共享与第三方服务

我们只在提供服务所必需的范围内与以下第三方共享信息：

  • 模型服务提供方：处理你通过托管模型或 Eonarc 提交的内容，具体提供方以后台实际启用的模型为准。它们按各自的隐私政策处理数据；
  • 邮件服务：用于发送注册与重置密码验证码，会获得你的邮箱和邮件内容；
  • GitHub：仅在你选择 GitHub 登录时参与授权；
  • 云服务器提供方：为我们提供服务器托管。

除此之外，只有在法律法规要求、有权机关依法要求，或为保护你、其他用户或公众的人身财产安全确有必要时，我们才会披露你的信息。

5. 存储地点与保存期限

我们的服务器位于中国香港。如果你在中国内地使用服务，你的信息会传输至香港存储和处理。使用服务即表示你了解并同意这一安排。

账号信息与云端内容在账号存续期间保存。托管模型调用记录保留 90 天。访问日志按服务器运维周期轮换。注销账号后，我们会在合理期限内删除或匿名化相关信息，备份中的副本在备份轮换后清除；法律法规另有要求的除外。

6. 安全措施

我们使用 HTTPS 加密传输；密码与恢复码以哈希保存；会话令牌在服务器上只保存摘要并定期轮换；模型服务密钥加密保存；Eonarc 任务在资源受限的隔离容器中运行。

任何系统都无法做到绝对安全。如发生个人信息安全事件，我们会按法律要求告知你并采取补救措施。

7. 你的权利

  • 查看与更正：在应用中查看和修改名称、头像等资料；
  • 管理登录：查看登录设备，退出单台设备或所有设备；
  • 删除：在 Eonarc 中可直接删除对话和账号；WenDou Agent 账号注销请发邮件至 zhangkongduan@gmail.com；
  • 撤回授权：可在 GitHub 设置中撤销对 WenDou Agent 的授权，可在系统设置中关闭电脑操控等系统权限。

行使上述权利或对本政策有疑问，请联系 zhangkongduan@gmail.com。我们会在 15 个工作日内答复。

8. 未成年人

我们的服务不面向未满 14 周岁的儿童。未满 18 周岁的用户应在监护人同意和指导下使用。如发现在未获监护人同意的情况下收集了儿童信息，我们会尽快删除。

9. 政策更新

我们可能会更新本政策。重大变更会在官网或应用内显著位置提示。更新后继续使用服务，即表示你接受更新后的政策。
